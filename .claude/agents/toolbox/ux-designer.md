# ux-designer 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：讀頁面HTML/CSS，找進入成本、觸控目標、斷點問題。
- **Bash**：`curl` 取實際頁面內容、檢查 CSS 斷點；🔴 內建瀏覽器全域禁用——需要真人
  視覺確認的一律列成「待人工確認」，不要假裝自己看過畫面。
- **WebSearch/WebFetch**：查手機端UX基準（觸控目標尺寸、認知負荷實證），補進
  `kb/ux-designer.md`。
