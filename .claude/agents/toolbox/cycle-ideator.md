# cycle-ideator 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：讀既有資料模型與文件，確認提的東西不是已經有了。
- **WebSearch/WebFetch**：找外部先例（其他 repo/產品怎麼做同一件事），你的選項要有
  「已有的先例」這一欄，這兩個工具是補這欄的主要方式。
- 🔴 **沒有 Edit/Write**——你只提案，不寫程式、不改檔案。

## 這個角色專屬的高層工具
- `board_tool.py write/kb-append`——強制，`kb/cycle-ideator.md` 該累積本專案特有的硬約束
  清單（例：純vanilla無建置流程）——一旦在某個WP因此排除過某個選項，下次直接套用不用
  重新推導。
