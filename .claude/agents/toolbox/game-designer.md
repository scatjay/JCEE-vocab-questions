# game-designer 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：讀計分規則、既有 XP/streak 邏輯，找學生會怎麼鑽的空間。
- **WebSearch/WebFetch**：查過度辯證效應、自我決定理論等實證邊界，補進 `kb/game-designer.md`。
- 🔴 **沒有 Edit/Write**——不寫程式、不改檔案。

## 這個角色專屬的高層工具
- `board_tool.py write/kb-append`——強制。
- `xp_sim.py`（**proposed，還沒建置**）——「先錯後修比一次答對划算」這個漏洞目前是
  靠純推理找出來的，沒有真的模擬過。這支工具建好後，給一套計分規則＋幾種學生策略
  （老實答/鑽漏洞），模擬跑出總分，讓「這個規則會不會被鑽」從推理變成算得出來的數字。
  **下次審查新的計分規則時，如果又靠純推理找漏洞，這是提案建置的具體理由。**
