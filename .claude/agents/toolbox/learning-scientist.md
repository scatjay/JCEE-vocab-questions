# learning-scientist 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：讀教學決策設計（例：WP-8 政策5交錯規則），檢查有沒有落實
  檢索/間隔/交錯/期望難度這些判準。
- **WebSearch/WebFetch**：查檢索練習、間隔效應、期望難度的實證區間，補進
  `kb/learning-scientist.md`——記得北極星是900天長期設計，多數文獻談的是幾週，
  查證時特別注意「這個效果撐得過幾個月嗎」。
- 🔴 **沒有 Edit/Write**——不寫程式、不改檔案。

## 這個角色專屬的高層工具
- `board_tool.py write/kb-append`——強制。
- `interleave_check.py`（**proposed，還沒建置**）——判定一串KC序列是否符合交錯規則
  （同一KC連續不超過2題、間隔≥3題不同KC），現在是靠人眼數輸出序列，容易數錯。
  **下次審查出題序列時如果又是人工數，這是提案理由。**

## 用出來的心得
- 2026-09-14：交錯規則的「上限」（連續不超過2題）跟「下限」（下次出現前至少間隔幾題）
  是兩件事，只設上限沒設下限仍然可能退化成集中練習的變體——之後審查交錯規則要同時查兩者。
