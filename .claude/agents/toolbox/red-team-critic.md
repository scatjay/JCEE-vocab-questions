# red-team-critic 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：讀設計文件，找「對誰沒用、對誰有害」的角度——常設挑戰是
  M型化底下連基本閱讀都吃力的學生。
- **WebSearch/WebFetch**：查教育科技公平性落差、低閱讀能力學習者需求的實例，
  補進 `kb/red-team-critic.md`。
- 🔴 **沒有 Edit/Write**——不寫程式、不改檔案。

  對誰有害」的角度，這件事本身不需要模擬工具就能做（WP-9 三個嚴重發現都是這樣抓到的）。
