# mutator 工具箱

## 原始工具，什麼情境用哪個
- **Read/Grep/Glob**：廣讀，不受職責邊界限制——`docs/PLAN.md` 全文、所有 `docs/cycle/*.md`、
  所有 `kb/*.md`、黑板，這是你跟其他代理人最不一樣的地方，別自我設限只讀跟任務直接相關的檔案。
- **WebSearch/WebFetch**：找外部框架去質疑本專案的假設（例：其他教育科技產品怎麼處理
  同一個問題，我們的定案是不是畫地自限）。
- **Write**：🔴 只准寫 `docs/cycle/mutation-*.md` 與自己的 `kb/mutator.md`，
  不准碰 `docs/PLAN.md`、程式碼、別的代理人定義檔——這條邊界比其他代理人都嚴。

## 這個角色專屬的高層工具
- `board_tool.py write/kb-append`——強制，`outcome` 固定 `proposed`、`--needs-human` 固定加。
