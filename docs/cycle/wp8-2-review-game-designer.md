## 核心循環

```
觸發：開 Hub / 碎片時間按鈕 / 番茄鐘提示
  → 行動：WP-8 選一題 → 學生作答
  → 回饋：對/錯即時顯示 → XP跳動(+10/+2/+15) → 「為什麼給你這題」一句話
  → 進展：HUD等級/連續天數 → session結束寫回RTDB → 下次帶著新θ回來
```

3 分鐘版本能不能單獨成立：能，但前提是 **WP-8 真的接管「下一題給什麼」**，不是退化成隨機叫一站的 `randomTen()`。

## 學生會怎麼鑽（三種，附堵法）

**鑽法 1（最大漏洞）：先錯後修比一次答對划算**
故意先答錯（+2）、下次遇到同一題馬上修好（+15）＝ 17 XP，比認真一次答對的 10 XP 高 70%。規則沒寫「修好」需要間隔多久才算數。
→ **怎麼堵**：`repairedAt` 前必須經過至少一次非同次 session 的再遇到，跟 WP-8 精熟判定的邏輯對齊，不能各寫各的。

**鑽法 2：挑軟柿子站刷 XP，迴避難站**
+10/+2 是每題固定值，不管難度、不管是否系統推薦。學生會挑 `wordwheel`／熟悉的 `cards` 而非 `gsat`，難度 targeting 被繞過。
→ **怎麼堵**：不是禁止自由選站（會傷到零設定碎片時間的公平性），而是給「照系統建議走」一點點一致性加成，差距不能大到讓自由探索（字根表、卡片）變成壞選擇。

**鑽法 3：每天正好 3 題保命，應付連續天數**
WP-1「當日完成≥3題才算數」是清楚寫在規則裡的數字門檻，時間破碎的學生會用最簡單的站 30 秒解決。`sessions` 資料會很漂亮但學習量趨近零——騙過「使用層級」評估，「學習層級」全軍覆沒。
→ **怎麼堵**：不當作弊來堵，而是把這 3 題的內容選擇權交給 WP-8——優先給 `cards` 今日到期或 `wrongItems`，讓「應付」的最低成本行為剛好也是系統最想要的（到期複習）。

## 逐條判定

- **獎勵指向**：+10/+2/+15 方向對，但只在「修錯題」被嚴格定義為跨時間再遇到才成立（見鑽法1）。這是動工前最需要釘死的一條。
- **節奏**：等級曲線前期好升，方向對；但 900 天裡「等級」數字在第 100 天後對多數學生會失去意義，**能力可見**比等級數字重要得多，目前是空白。
- **失敗處理**：答錯不扣分方向正確。但**領域簡報 §3 明確要求的「補做/寬限」機制，WP-1/WP-3 都沒看到**，這是缺口不是我鑽出來的漏洞。
- **能力可見**：目前整份計畫幾乎只有 XP/等級/streak 這些外在指標。WP-8 的精熟判定是好素材，但沒被設計成學生看得到的東西（只在資料層"標記"，WP-3 的儀表板規格沒提到「精熟徽章」）。**沒有能力可見，XP 鷹架撐不了 900 天**——中後期學生會發現數字在漲但看不出真的變強，外在動機會塌陷。

## 為 900 天設計的部分

- 等級曲線撐得過第 3 週，撐不過第 20 週（次方曲線長期通膨沒被討論）。
- 交錯規則本身是對的長期設計，但**「現在覺得亂是正常的」這句話寫在領域簡報卻沒進到 WP-8/WP-3 規格**——3 分鐘碎片時間若只做 5-6 題、KC 每 2 題就跳一次，第一次使用者會覺得「這系統很亂」而不是「這是刻意設計」。建議「為什麼給你這題」那句話也要解釋切換本身。
- streak 3 題門檻若不修正選題來源，900 天會被「最省力應付」磨掉大半價值——習慣一旦形成，改規則的阻力遠大於一開始就設計對。

## WP-9 底線偵測：機制比文案誠實

文案做對了（不用「加油/再試一次」、明講不是你的問題、路由到真實存在的較低階入口）。但兩個**機制層**風險文案蓋不住：

1. **觸發那天 streak 算不算數？** 若因系統判定觸底而不出題導致當天沒練到 3 題、streak 斷掉——他明明有出現有嘗試，卻因系統判斷被記為「沒完成」，違反「斷掉的懲罰要溫和」紅線。**floor-hit 當天的 session 要能算已完成**，streak 不能因為被導去 roots/wordwheel 而斷掉。
2. **重複觸發會不會變成每天被提醒「這系統幫不上你」？** 連續好幾天低於門檻，若每次都重播完整的「誠實告知＋降階」流程，累積起來仍會被聽成「你就是不行」，即使用詞沒踩黑名單。**建議：第一次完整說明＋降階，之後默默持續給降階內容，不必每次重播那句話**，除非隔了夠長時間或學生自己回到較難內容又再度觸底。

機制永遠比文案誠實：嘴巴說不放棄，若系統動作（扣streak、天天提醒）做出放棄的樣子，設計初衷會被自己的機制打臉。
